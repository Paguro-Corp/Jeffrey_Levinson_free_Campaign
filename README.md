# Jeffrey Levinson, Three Evenings

Social media campaign proposal for Jeffrey Levinson by Danna Olarte, Pagurai Creative.

Three one-week Instagram and Facebook campaigns, each built around one clutch and one evening:

- **Still Reachable**, Elina Plus Malbec
- **Her Evenings**, Finley Touring Red
- **No Time to Change**, Elina Plus Mirrored Black Chrome

Open `index.html` in a browser, or enable GitHub Pages on the `main` branch to publish it. The hero includes an interactive 3D clutch (Three.js).
